
# django-todo-app

A Todo List web application built using Django. Users can add, update, delete. This project demonstrates basic CRUD operations in Django.

---

## 🚀 Features

- Add new tasks
- Update existing tasks
- Delete tasks
- Simple and clean UI

---

## 🛠 Tech Stack

- Python
- Django
- HTML
- CSS
- SQLite Database

---

## 📂 Project Structure

django-todo-app/
│
├── todoapp/
├── templates/
├── db.sqlite3
├── manage.py


---

## ▶️ How to Run This Project

1. Clone the repository
git clone https://github.com/hellygajjar87/django-todo-app.git

2. Go into the project folder
3. Run the server py manage.py runserver
4. Open in browser:

http://127.0.0.1:8000/
